PositionBar 0.8.0

새로운 기능
- macOS에서 Hyperliquid와 Polymarket의 읽기 전용 브라우저 지갑 연결을 추가했습니다. MetaMask, OKX Wallet, Coinbase Wallet 등 감지된 브라우저 지갑을 서명이나 체인 전환 없이 로컬에서 연결하거나, 이메일 로그인 계정은 플랫폼 포털을 열어 공개 주소를 직접 붙여넣을 수 있습니다. Hyperliquid는 에이전트 지갑의 메인 계좌 확인과 서브 계좌 일괄 가져오기를 지원하며, Polymarket은 연결된 계좌 지갑을 조회해 확인합니다.
- macOS에 부드러운 정기 업데이트 알림을 추가했습니다. 백그라운드 업데이트 확인 시 포커스를 빼앗거나 다른 창 뒤에 가려지지 않으며, 시스템 알림 권한을 요청하지 않고 패널 톱니바퀴 버튼에 강조 색 점을 표시하고 업데이트 메뉴를 「사용 가능한 업데이트」로 전환합니다.

개선
- 계약 목록 가치와 격리 증거금 귀속 기준을 계좌 순자산에 맞췄습니다. 교차·포트폴리오 증거금 계약은 이제 부호가 포함된 미실현 손익만 표시해 목록 행의 합계가 계좌 순자산과 직접 일치하며, 검증된 격리 증거금 계약(OKX, Binance USD-M 및 COIN-M, Gate, Bitget)은 격리 증거금과 미실현 손익을 합산해 표시하고 해당 증거금을 기반 지갑 행에서 차감해 중복 계산을 방지합니다.
- 브라우저에서 OAuth 로그인(OKX, Longbridge, Futu, moomoo)이나 지갑 연결(Hyperliquid, Polymarket) 콜백이 완료되면 macOS가 해당 계좌 연결 창과 설정 창을 즉시 전면으로 가져오며, 브라우저 콜백·지갑 연결·로컬 MCP 승인 페이지를 10개 언어의 통합 로컬 WebUI로 일신했습니다.
- 안정성 향상을 위해 macOS에 개인정보를 철저히 제거한 충돌·실행 성능·수명 주기 진단을 추가했습니다. IP 주소와 개인 식별 정보는 제거되며 거래소·증권사 네트워크 트래픽, 자격 증명, 계좌 정보 및 보유 자산은 수집에서 완전히 제외됩니다.

수정
- macOS 다중 디스플레이 환경에서 메뉴 막대 패널과 보조 창의 위치 동작을 수정했습니다. 다른 화면의 메뉴 막대 아이콘을 클릭하면 패널이 해당 화면으로 바로 이동하고, 고정된 패널은 해당 화면의 모든 Space와 전체 화면 앱 위에서 유지되며, 패널 상단이 메뉴 막대 아래에 맞춰지고 실시간 문구 길이에 따라 흔들리지 않습니다. 설정 및 정보 창도 Space를 넘어 안정적으로 전면에 표시됩니다.
- Binance 현물·마진·적립·펀딩 계좌와 Bitget, Gate 계좌의 기본 통화 암호화폐 잔고가 현금 잔고와 동일한 최상위 환율 경로로 일관되게 평가되도록 수정했으며, 온체인 지갑 토큰은 계속 별도로 격리합니다.
- 로컬에 캐시된 교차 환율에 무손실 39자리 128비트 Decimal 값이 포함될 때 자산 이력 차트를 불러오지 못하던 문제를 수정했습니다.
