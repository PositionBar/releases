PositionBar 0.3.0

새로운 기능
- 로컬 MCP가 이제 OAuth를 사용하며 PositionBar에서 네이티브 승인 확인을 표시합니다. 액세스는 클라이언트별로 부여되고 설정 → 통합에서 취소할 수 있으며, 토큰은 취소할 때까지 앱을 다시 시작해도 유효합니다.
- 게시된 자산 스냅샷, 기존 계정 이름 및 활성 상태, 앱 환경설정을 위한 MCP 도구를 추가했으며 메뉴 막대 템플릿 도구도 유지됩니다.

개선
- 로컬 MCP 비즈니스 액세스는 이제 `/mcp`로만 제공되며 기존 `/v1/*` REST 엔드포인트는 제거되었습니다. REST를 사용하던 클라이언트는 MCP로 전환해야 합니다.
- 통합 화면에서 복사 가능한 연결 지침과 클라이언트별 취소 및 실패 시 재시도를 지원하는 권한 목록을 제공합니다.
