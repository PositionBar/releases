PositionBar 0.7.2

新增
- 新增富途與 moomoo 支援：在瀏覽器中完成唯讀登入即可連線證券現金與融資帳戶，同步多幣別現金、股票、ETF、選擇權、港股輪證及歷史行情與成交紀錄，並透過 iCloud 鑰匙圈同步至 iOS 唯讀檢視。

改善
- OKX 與長橋全面切換為瀏覽器唯讀登入，停用舊版 API Key 與掃碼登入；OKX 支援依區域站點登入，並隔離選用機器人與跟單模組的權限錯誤，不再影響核心餘額與持倉同步。
- 重新設計 macOS 設定視窗，採用原生分組表單樣式與統一偏好設定標題列，重排一般、帳號與整合頁面版面；將隱藏小額資產合併為單一「最低顯示價值」輸入框（設為 0 時顯示全部資產），支援寬度隨輸入自適應並改善初始焦點與捲動體驗。

修正
- 修正 Bitget 統一帳戶同步問題：相容科學記號數值與空清單回應，過濾非加密資產與異常行情項目以確保現貨與合約報價及圖表穩定載入，並在請求失敗時顯示明確錯誤碼。
- 修正當日早快照尚未關聯市場目錄時，同日補齊行情後部分持倉仍缺少今日損益的問題。
- 修正刪除帳戶時可能誤刪其他留存帳戶歷史估值序列及跨帳戶錯價的問題，同時修正快速切換本機 MCP 開關時的狀態競態，並補齊帳戶操作錯誤的十語在地化提示。
