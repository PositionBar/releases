PositionBar 0.3.0

新機能
- ローカル MCP が OAuth を使用し、PositionBar でネイティブの承認確認を表示するようになりました。アクセスはクライアントごとに付与され、「設定 → 統合」から取り消せます。トークンは取り消すまでアプリを再起動しても有効です。
- 公開済みの資産スナップショット、既存アカウントの名前と有効状態、アプリの環境設定のための MCP ツールを追加し、メニューバーテンプレートのツールも維持しました。

改善
- ローカル MCP の業務アクセスは `/mcp` のみで提供されるようになり、旧 `/v1/*` REST エンドポイントは削除されました。REST を利用していたクライアントは MCP に切り替える必要があります。
- 「統合」でコピー可能な接続手順と、クライアントごとの取り消しおよび失敗時の再試行に対応した承認一覧を提供します。
