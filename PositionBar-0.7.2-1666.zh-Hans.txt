PositionBar 0.7.2

新增
- 新增富途与 moomoo 支持：在浏览器中完成只读登录即可连接证券现金与融资账户，同步多币种现金、股票、ETF、期权、港股轮证及历史行情与成交记录，并通过 iCloud 钥匙串同步至 iOS 只读查看。

优化
- OKX 与长桥全面切换为浏览器只读登录，停用旧版 API Key 与扫码登录；OKX 支持按区域站点登录，并隔离可选机器人与跟单模块的权限报错，不再影响核心余额与持仓同步。
- 重新设计 macOS 设置窗口，采用原生分组表单样式与统一偏好标题栏，重排通用、账号与集成页面布局；将隐藏小额资产合并为单一「最低展示价值」输入框（设为 0 时显示全部资产），支持宽度随输入自适应并优化初始焦点与滚动体验。

修复
- 修复 Bitget 统一账户同步问题：兼容科学计数法数值与空列表响应，过滤非加密资产及异常行情条目以确保现货与合约报价及图表稳定加载，并在请求失败时显示明确错误码。
- 修复当天早快照尚未关联市场目录时，同日补齐行情后部分持仓仍缺少今日盈亏的问题。
- 修复删除账户时可能误删其他留存账户历史估值序列及跨账户串价的问题，同时修复快速切换本地 MCP 开关时的状态竞态，并补齐账户操作错误的十语本地化提示。
