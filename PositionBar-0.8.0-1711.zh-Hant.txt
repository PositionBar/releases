PositionBar 0.8.0

新增
- 新增 macOS 端 Hyperliquid 與 Polymarket 瀏覽器唯讀連接錢包流程：可在本機偵測並連接瀏覽器錢包擴充功能（如 MetaMask、OKX Wallet、Coinbase Wallet 等），無需簽名或切換網路，也支援電子郵件登入使用者開啟官網後直接貼上公開位址；Hyperliquid 支援 Agent 轉主帳戶確認與子帳戶批次匯入，Polymarket 支援自動解析並確認對應的帳戶錢包。
- 新增 macOS 溫和排程更新提醒：背景自動檢查發現新版本時不再搶佔焦點或藏在其他視窗底層，而是在主面板右上角齒輪按鈕顯示強調色提示點，並將更新選單切換為「有可用的更新」，全程不要求系統通知權限。

改善
- 對齊合約清單價值與逐倉保證金歸屬口徑：全倉與組合保證金合約現依帶符號未實現損益顯示，使清單各列可直接彙總為帳戶淨權益且不隨槓桿波動；已核驗的逐倉合約（OKX、幣安 U 本位與幣本位、Gate、Bitget）依「逐倉保證金 + 未實現損益」顯示，並自對應錢包列扣減已佔用保證金，避免重複計入。
- 自瀏覽器完成 OAuth 登入（OKX、長橋、富途、moomoo）或錢包連接（Hyperliquid、Polymarket）回呼後，macOS 會立即將對應的帳戶對話框與設定視窗帶到前景；同時統一升級瀏覽器回呼、錢包連接與本機 MCP 授權頁的十語內嵌介面。
- 於 macOS 端接入嚴格去識別化的當機、啟動效能與生命週期診斷以提升穩定性：預設不收集個人識別資訊與 IP 位址，並完全排除交易所／券商網路請求、憑證、帳戶資訊與持倉資料。

修正
- 修正 macOS 多螢幕場景下的主面板與輔助視窗定位問題：跨螢幕點擊選單列圖示時面板直接移至目標螢幕開啟，釘選狀態的面板在目標螢幕跨桌面 Space 與全螢幕應用程式上方保持可見，面板緊貼系統選單列底邊且不隨即時文案寬度抖動，設定與關於視窗可跨 Space 可靠前置聚焦。
- 修正幣安現貨、槓桿、理財、資金帳戶及 Bitget、Gate 中原生幣別加密貨幣餘額估值口徑不一致的問題，統一經頂層匯率路徑估值，同時保持鏈上錢包代幣隔離不錯價。
- 修正本機快取的交叉匯率包含無損 39 位 128-bit Decimal 數值時，統計頁權益歷史圖表載入失敗的問題。
