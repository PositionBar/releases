PositionBar 0.8.0

新增
- 新增 macOS 端 Hyperliquid 与 Polymarket 浏览器只读连钱包接入：可在本地发现并连接浏览器钱包插件（如 MetaMask、OKX Wallet、Coinbase Wallet 等），无需签名或切链，也支持邮箱登录用户打开官网后直接粘贴公开地址；Hyperliquid 支持 Agent 转主账户确认与子账户批量导入，Polymarket 支持自动解析并确认对应的账户钱包。
- 新增 macOS 温和定时更新提醒：后台自动检查发现新版本时不再弹出抢焦或藏在其他窗口底层，而是在主面板右上角齿轮按钮显示强调色提示点，并将更新菜单切换为「有可用更新」，全程不申请系统通知权限。

优化
- 对齐合约列表价值与逐仓保证金归属口径：全仓与组合保证金合约现按带符号未实现盈亏展示，使列表各行可直接汇总为账户净权益且不随杠杆波动；已核验的逐仓合约（OKX、币安 U 本位与币本位、Gate、Bitget）按「逐仓保证金 + 未实现盈亏」展示，并从对应钱包行扣减已占用保证金，避免重复计入。
- 从浏览器完成 OAuth 登录（OKX、长桥、富途、moomoo）或钱包连接（Hyperliquid、Polymarket）回调后，macOS 会立即将对应的账户弹窗与设置窗口拉至前台；同时统一升级了浏览器回调、钱包连接与本地 MCP 授权页的十语嵌入式界面。
- 在 macOS 端接入严格脱敏的崩溃、启动性能与生命周期诊断以提升稳定性：默认不收集个人身份信息与 IP 地址，并完全屏蔽交易所/券商网络请求、凭据、账户信息与仓位数据。

修复
- 修复 macOS 多屏场景下的主面板与辅助窗口定位问题：跨屏点击菜单栏图标时面板直接迁至目标屏打开，固定态面板在目标屏跨桌面 Space 与全屏应用上方保持可见，面板紧贴系统菜单栏底边且不随实时文案宽度抖动，设置与关于窗口可跨 Space 可靠前置聚焦。
- 修复币安现货、杠杆、理财、资金账户及 Bitget、Gate 中原生币种加密货币余额估值口径不一致的问题，统一经顶层汇率路径估值，同时保持链上钱包代币隔离不串价。
- 修复本地缓存的交叉汇率包含无损 39 位 128-bit Decimal 数值时，统计页权益历史图表加载失败的问题。
