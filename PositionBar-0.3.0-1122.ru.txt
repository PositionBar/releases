PositionBar 0.3.0

Новое
- Локальный MCP теперь использует OAuth с нативным запросом подтверждения в PositionBar. Доступ предоставляется отдельно для каждого клиента и отзывается в разделе «Настройки → Интеграции»; токены действуют после перезапуска приложения до момента отзыва.
- Добавлены инструменты MCP для опубликованных снимков активов, названий и состояния существующих счетов, а также настроек приложения; инструменты шаблона строки меню сохранены.

Улучшения
- Бизнес-доступ локального MCP теперь предоставляется только через `/mcp`; устаревшие REST-маршруты `/v1/*` удалены. Клиентам, использовавшим REST, нужно перейти на MCP.
- В разделе «Интеграции» теперь доступны инструкции по подключению для копирования и список авторизаций с отзывом для каждого клиента и повтором при ошибке.
