PositionBar 0.7.2

新機能
- Futu と moomoo に対応しました。ブラウザから読み取り専用でサインインして現金・信用証券口座を接続し、複数通貨の現金、株式、ETF、オプション、香港ワラント、価格履歴および約定履歴を同期でき、iCloud キーチェーン経由で iOS でも読み取り専用で閲覧できます。

改善
- OKX と Longbridge をブラウザからの読み取り専用サインインに統一し、従来の API キーおよび QR コード接続を廃止しました。OKX は地域別サイトでのサインインに対応し、任意のボット・コピートレードの権限エラーを主要な残高・ポジション同期から分離します。
- macOS の「設定」ウィンドウをネイティブのグループフォームと統一タイトルバーで刷新し、「一般」「アカウント」「連携」のレイアウトを整理しました。少額資産フィルタを単一の「表示する資産の最低価値」入力欄（0 で全資産を表示）に統合し、入力幅の自動調整と初期フォーカス・スクロール挙動を改善しました。

修正
- Bitget 統合取引口座（UTA）の同期を修正しました。指数表記の数値や空・省略されたリスト項目に対応し、非暗号資産や不正な市場データを除外して現物・契約の価格とチャートを安定表示させ、リクエスト失敗時に明確なエラーコードを表示します。
- 当日の開始スナップショット時点で市場メタデータが未紐付けだった保有銘柄について、同日の価格履歴が取得されたあとも当日損益が欠落していた問題を修正しました。
- 口座削除時に他口座の評価履歴が誤って削除されたり口座間で評価価格が取り違えられたりする不具合を修正し、ローカル MCP スイッチの高速切り替え時の競合を解消して、口座操作エラーの多言語メッセージを追加しました。
